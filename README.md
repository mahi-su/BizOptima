# BizOptima – AI Powered Business Analytics & Profit Prediction Platform

## Overview
BizOptima is a smart business analytics web application built using Flask, Scikit-learn, HTML, CSS, and JavaScript.  
The platform helps users analyze business performance, predict profit trends, calculate business health scores, and generate intelligent suggestions using Machine Learning.

The system provides secure JWT-based authentication, interactive dashboards, predictive analytics, risk analysis, CSV/PDF export functionality, and historical data tracking.

---

# Main Features

- User Registration and Login

- Business Risk Analysis
- Business Health Score Calculation
- Smart AI-Based Suggestions
